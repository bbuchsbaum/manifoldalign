# Compute Gradient of Edge Consistency Regularizer (Dispatcher)

Compute Gradient of Edge Consistency Regularizer (Dispatcher)

## Usage

``` r
compute_edge_gradient(S, networks, use_cpp = FALSE)
```

## Arguments

- S:

  Current transport plan

- networks:

  Network structures

- use_cpp:

  Whether to use C++ implementation

## Value

Gradient matrix
