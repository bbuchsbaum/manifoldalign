# Compute Squared Euclidean Distance Matrix (Dispatcher)

Compute Squared Euclidean Distance Matrix (Dispatcher)

## Usage

``` r
compute_squared_distances(X1, X2, use_cpp = FALSE)
```

## Arguments

- X1:

  First matrix (n1 x d)

- X2:

  Second matrix (n2 x d)

- use_cpp:

  Whether to use C++ implementation

## Value

Distance matrix (n1 x n2)
