# Generate Performance Report

Creates a comprehensive performance analysis report

## Usage

``` r
generate_parrot_performance_report(
  output_file = "parrot_performance_report.txt"
)
```

## Arguments

- output_file:

  Path to save the report

## Value

A character string containing the formatted performance report,
invisibly

## Examples

``` r
if (FALSE) { # \dontrun{
generate_parrot_performance_report(tempfile(fileext = ".txt"))
} # }
```
