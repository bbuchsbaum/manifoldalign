# Global geometry aligner (native multi-view)

Global geometry aligner (native multi-view)

## Usage

``` r
global_geo_aligner()
```

## Value

An object of class \`c("global_geo_aligner", "aligner")\` representing a
global geometry alignment algorithm descriptor.

## Examples

``` r
algo <- global_geo_aligner()
class(algo)
#> [1] "global_geo_aligner" "aligner"           
```
