# Block B: Multi-scale Descriptors - Corrected

Block B: Multi-scale Descriptors - Corrected

## Usage

``` r
compute_grasp_descriptors(bases, q_descriptors, sigma = 0.73)
```

## Arguments

- bases:

  List of spectral bases

- q_descriptors:

  Number of descriptor functions

- sigma:

  Diffusion parameter

## Value

List of descriptor matrices
