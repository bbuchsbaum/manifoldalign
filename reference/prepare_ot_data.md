# Extract data from hyperdesign and apply preprocessing

Extract data from hyperdesign and apply preprocessing

## Usage

``` r
prepare_ot_data(data, preproc = NULL)
```

## Value

A list with elements \`X_list\` (list of data matrices), \`n_samples\`
(integer vector), \`n_domains\` (integer), \`domain_names\` (character
vector), and \`data\` (the preprocessed hyperdesign).
