# Solve Sinkhorn Transport (Optimized Primal Scaling)

Solve Sinkhorn Transport (Optimized Primal Scaling)

## Usage

``` r
solve_sinkhorn_transport(cost_matrix, tau, max_iter, tol)
```

## Arguments

- cost_matrix:

  Dense cost matrix

- tau:

  Entropy regularization parameter

- max_iter:

  Maximum iterations

- tol:

  Convergence tolerance

## Value

Transport plan matrix
