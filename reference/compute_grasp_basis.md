# Block A: Spectral Basis Construction - Corrected

Block A: Spectral Basis Construction - Corrected

## Usage

``` r
compute_grasp_basis(strata, ncomp, use_laplacian = TRUE)
```

## Arguments

- strata:

  List of data domains

- ncomp:

  Number of spectral components

- use_laplacian:

  Whether to use Laplacian normalization

## Value

List of spectral bases for each domain
