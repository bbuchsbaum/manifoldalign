# Solve Diagonal Map to Anchor

Finds the diagonal matrix C that best maps from a graph's aligned
representation to the anchor representation.

## Usage

``` r
solve_diagonal_map(desc, basis, M, Z)
```

## Arguments

- desc:

  Descriptor matrix for graph

- basis:

  Spectral basis for graph

- M:

  Rotation matrix for graph

- Z:

  Anchor coefficient matrix

## Value

Diagonal mapping matrix
